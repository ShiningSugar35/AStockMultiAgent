# 给 GPT 的复核指令

## 任务

你是一位价值投资方法论审阅者。请读取附件 `复核工作表_价值投资功法.xlsx`，逐条审阅每一行数据，并在[复核结论]列填写你的判断。

## 文件说明

这是《价值投资功法》（Mr.Dang 著）的论点单元审核表。每一行代表书中一个被机器自动拆分的[论点单元]（Argument Unit），你需要判断机器的拆分和分类是否合理。

### 各列含义

| 列名 | 说明 |
|---|---|
| 页码 | 该书第几页 |
| 论点范围 | 该页第几段到第几段被合并为一个论点 |
| 涉及主题 | 机器判断该论点属于哪个投资维度（行业分析/财务质量/估值/风险/买入/卖出/商业模式/选股/失败案例等） |
| 复核原因 | 机器标记为什么需要人工复核（含图片/依赖链不完整/只有背景信息无结论等） |
| 图片 | Y=该论点所在页包含图片/图表 |
| 可信度 | 机器对该论点的主题相关性评分（0-1） |
| 完整度 | 机器对该论点的方法完整性评分（0-1） |
| 原文预览 | 从 PDF 提取的该页原文片段，供你判断上下文 |
| 复核结论 | **待你填写** |

## 审阅标准

1. **论点是否成立**：是否构成完整投资方法论点，还是背景/过渡/零散信息？
2. **主题归类是否准确**：机器标注的涉及主题是否符合原文内容？
3. **是否值得收录**：对投资决策有实质帮助，还是泛泛而谈？

## 结论填写规范

- **通过**：论点成立、分类准确、有投资方法价值
- **需修改**：论点大致合理但范围需调整，或主题分类需修正（注明建议）
- **驳回**：不是投资方法论点（背景介绍/目录页/重复内容/广告等）
