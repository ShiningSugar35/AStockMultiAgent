## 一手来源与采用决定

### S1：CFA Institute，2026 Equity Valuation: Applications and Processes

来源：`https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/equity-valuation-applications-and-processes`（2026课程公开摘要，本次访问 2026-09-17）。

原资料把理解业务、预测经营、选择适合公司的估值模型、估值与应用结论分开，并强调行业前景、竞争地位、策略与盈利质量。资料也区分自上而下和自下而上的研究路径，模型应适配公司特点、资料质量及用途。

决定：**ADAPT_PATTERN**。让公司经营/行业差异参与候选发现；同时保留“待验证线索”与“完成估值”的边界。接现有 industry-value-chain、23个公共行业包、WP-32 金融行业口径适配与既有估值模型。不照搬海外阈值，不复制课程内容，不以 CFA 名义声称选股命中率。

### S2：AQR，Quality Minus Junk

来源：`https://www.aqr.com/Insights/Research/Working-Paper/Quality-Minus-Junk`（页面日期 2018-11-05；本次访问 2026-09-17）。

作者讨论企业质量与质量的价格，而不是只把低价格倍数当作价值。公开摘要涉及盈利、增长和管理质量，并明确研究用途及历史表现限制。

决定：**ADAPT_PATTERN＋SHADOW_EXPERIMENT**。采用质量与价格分别检验的思路，为质量/价值发现增加盈利兑现、现金支持和业务差异；具体中国市场字段、阈值及候选增益必须由本地证据和 WP-42 当前样本对照验证。AQR 的海外历史结果不能作为本项目当前有效性的证据，也不因此给系统重新增加回测工作流。

### S3：QuantConnect / LEAN，Fundamental Universes

来源：`https://www.quantconnect.com/docs/v2/writing-algorithms/universes/equity/fundamental-universes`（当前官方文档，本次访问 2026-09-17）。

文档展示基本面股票池、先缩小再细筛、明确处理缺失值、行业分类、异步选择和限制资产订阅规模。示例说明筛选与后续资产处理可分离，而不是对全市场全部对象做昂贵分析。

决定：**ADAPT_PATTERN**。全市场轻量列式事实→多通道有限候选→少量语义和深研；先排适用性与缺失状态，再做通道内比较。不能照搬“只留最活跃若干只后全部细筛”，否则冷门经营机会仍在入口消失；本地保留独立经营/事件发现支路。缺失字段只退出依赖该字段的已验证路径，不在所有路径删除该公司。

不引入 LEAN 引擎、Morningstar 付费数据、其美国时间安排或交易子系统。这里仅借鉴工程结构，未复制代码，新增依赖为0。

### S4：Microsoft Qlib，Data Layer: Data Framework & Usage

来源：`https://qlib.readthedocs.io/en/latest/component/data.html`（当前官方文档，本次访问 2026-09-17；页面显示 0.9.8.dev11）。

文档将数据加载、处理、数据集分层，提供表达式/数据集缓存和共享处理器。可复用的启示是让同一特征与同一输入计算一次，并让多个研究问题共享结果。

决定：**ADAPT_PATTERN**。复用本地 Parquet／ObjectStore 和 WP-32/34 的依赖失效，建立派生轻量视图；缓存绑定证券、事实内容、公式、单位、报告期与方法版本。**不引入完整 Qlib、Redis、训练框架或新的事实仓库**。Qlib 的填0/均值、未来收益标签等训练示例不适用于本项目事实缺失处理或本次实时发现验收，不照搬。

### S5：muxuuu/serenity-skill

来源：`https://github.com/muxuuu/serenity-skill`（维护者原仓库，MIT；本次访问 2026-09-17）。

当前 README 明确采用需求→价值链→供应瓶颈→公司→公告/财报与风险核验的流程，强调扩产和替代难度；并说明项目是独立的公开方法论工具。2026-09-14 示例是材料研究示例，不是自动更新的买入清单；当前说明偏好用证据和推理解释研究优先级，而非一个综合数字评分。

决定：**ADAPT_PATTERN**。把瓶颈线索发现前移，补真实业务暴露映射；候选阶段不把行业关键词等同于不可替代性或利润归属。已有 `IndustryBottleneckSkill` 可以复用，缺口是发现与证据编译的接入，不再安装第二个包。

当前在线 HEAD 不等于本地已审计版本。本地仍以 `configs/research_skills.yaml` 的 v5 上游审计与 LocalAdaptationRelease 为准；本次不升级 pin、不改变其权限，不把该仓库误称 Serenity 本人官方认证实现。

### S6：haskaomni/serenity-skill

来源：`https://github.com/haskaomni/serenity-skill`（维护者原仓库，MIT；本次访问 2026-09-17）。

原仓库列出事件传导、贝叶斯增长、基本面与均线健康、TAM 修正 PEG、买方报告、Juglar 周期六个方法。事件方法强调新闻到需求、财务和验证路径；周期方法区分行业、公司经营与股票阶段。

决定：**ADAPT_PATTERN**。事件/周期适合贡献候选命题，增长和估值适合有限候选复核，均线适合时机，报告组织不参与选股。沿用已有本地合同和同族/同组选取限制，不把六个方法当六位独立投委会成员；上游概率、分数和组合措辞均须服从本地证据、估值与组合权限。

## 不采用的方案

1. 不做作者投票或一人一票的加权选股。复述同一投资逻辑不能成为独立证据；作者粉丝数和仓库 Stars 不证明收益或适用性。
2. 不把全部技能一次性塞进全市场模型提示词，也不要求全市场逐股完整财报研究。增加的调用量与当前 35/40/45 分钟目标冲突。
3. 不新装另一个多 Agent 投研系统或全套量化引擎。现有 Provider、行业核心、知识服务、Serenity 和研究任务图已经具备所需基本分层。
4. 不把所有行业用统一 PE/PB/现金流阈值筛掉；不把纯新闻热度、股价回撤或放量视为已证明经营价值。
5. 不采用看上去精确的通用综合分、默认均值填充或静默权重重归一化。复杂命题用必要条件、证据强度、未知和反证分开表述。
