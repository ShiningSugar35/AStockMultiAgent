# 业务能力矩阵

## 说明
以下能力由首次体检口径填写，字段定义如下：
- **用户入口**：用户可直接调用的入口与接口
- **是否可运行**：基于本地审计文档与 git 证据
- **依赖**：功能依赖的来源/模块
- **证据**：对应事实来源
- **测试**：已执行或已记录的验收项
- **限制**：当前边界与风险

| 能力 | 用户入口 | 是否可运行 | 依赖 | 证据 | 测试 | 限制 |
|---|---|---|---|---|---|---|
| 行情下载与时序复盘（5m） | `astock` CLI（`sync-5m`） | 部分 | Provider/SQLite/ObjectStore | `验收报告.md`：参考数据口径与阶段状态 | 部分（阶段验收） | 全市场联动未作为默认链路 |
| 公司动作与财务同步 | `astock` CLI（`sync-calendar` / `sync-daily` / `sync-financial`） | 部分 | Provider（bao stock / direct HTTP） | `验收报告.md`、`configs/financial_sources.yaml` | 部分 | 二级结构化与 `source_snapshot` 阐释仍需外部确认 |
